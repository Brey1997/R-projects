# My Projects

A structured portfolio of analytics, machine learning, reporting, and dashboard projects created with R, Quarto, Power BI, and presentation tools.

## Project directory

| Project | Focus | Files |
|---|---|---|
| [FIFA Player Ratings](projects/fifa-player-ratings/) | Analysis of how age, potential, value, and preferred foot relate to overall ratings | R analysis and Word report |
| [Mental Health Prediction](projects/mental-health-prediction/) | Digital transformation strategy for improving mental-health prediction | PDF report |
| [Appointment Tracker](projects/appointment-tracker/) | Appointment tracking and reporting | Power BI dashboard |
| [Job Tracker](projects/job-tracker/) | Job application tracking and reporting | Power BI dashboard |
| [Garment Factory Machine Learning](projects/garment-factory-machine-learning/) | Machine-learning analysis of garment-factory data | Quarto analysis |
| [US Mortgage Rates](projects/us-mortgage-rates/) | Analysis and presentation about mortgage rates in the United States | PowerPoint presentation |
| [Salaries Dashboard](projects/salaries-dashboard/) | Salary analysis and reporting | Power BI dashboard |
| [Student Performance](projects/student-performance/) | Student performance analysis | PDF report |
| [Consumer Protection Text Mining](projects/consumer-protection-text-mining/) | Text-mining analysis for consumer protection | PDF report |
| [Traffic Accidents](projects/traffic-accidents/) | Traffic-accident analysis | PowerPoint presentation |

## Repository structure

Each project has its own folder under `projects/`. Related source files, dashboards, reports, and presentations stay together so the portfolio is easier to browse and maintain.

## Tools represented

- R
- Quarto
- Power BI
- Microsoft Word
- Microsoft PowerPoint
